# Become a Sponsor

Sponsorship keeps Udodi independently maintained: documentation, tests, performance work, releases, and long-term stewardship of the project.

Udodi remains free and open source. Contributions of any size fund focused maintenance and improvement, not influence over the roadmap or exclusive access to the runtime.

  <a class="sponsor-cta-btn" href="https://github.com/sponsors/udodi-js" target="_blank" rel="noopener noreferrer">Become a sponsor on GitHub</a>
</div>

## Why sponsor?

### Individuals

If Udodi is useful in your work or learning, sponsorship is a direct way to fund continued upkeep. Even a modest monthly amount supports real maintenance.

### Businesses and teams

If you ship products on Udodi, or evaluate it for production use, sponsorship helps keep the foundation you depend on actively maintained.

Higher tiers include public recognition on the website and in project materials. Recognition is a thank-you. It does not purchase feature priority, roadmap control, or exclusive rights to core functionality.

## How to become a sponsor

Supporting Udodi is handled through **[GitHub Sponsors](https://github.com/sponsors/udodi-js)**. The process is straightforward:

1. Open [GitHub Sponsors](https://github.com/sponsors/udodi-js) page.
2. Choose a sponsorship tier and select a **monthly** or **one-time** contribution, where available.
3. Complete the sponsorship through GitHub.
4. After activation, GitHub shows a confirmation message and might display further instructions.

## Bronze and above

The confirmation message for **Bronze**, **Silver**, **Gold**, and **Platinum** sponsors includes a link to a form that collects the information required for public recognition:

- **GitHub username or organization**: matches your submission to your GitHub Sponsors account
- **Name or company name**: shown in Udodi sponsor recognition
- **Website URL**: linked from eligible sponsor displays
- **Logo**: used where the tier includes logo placement
- **Notes**: optional extra context
- **Public recognition consent**: confirmation that Udodi may display the submitted name, logo, and website in official project materials

Public recognition applies while your eligible GitHub Sponsors sponsorship remains active, and may be updated or removed if the sponsorship ends or the submitted details change.

### After you submit the form

We verify the sponsorship and review the submitted information and logo. Once approved, your details can appear in the appropriate Udodi sponsor displays.

To update sponsor information later, submit the new details through the same form so public recognition stays current.

## What sponsorship supports

- Ongoing maintenance and bug fixes
- Documentation and examples
- Testing and reliability
- Performance investigation and improvement
- Developer experience and tooling
- Continued evolution of the runtime and ecosystem

## What sponsorship does not provide

Sponsorship funds sustainability. It is not a commercial support contract and does not control the project.

It does **not** guarantee:

- Feature implementation or roadmap placement
- Priority issue resolution
- Specific development deadlines
- Unlimited private technical support
- Exclusive access to core framework functionality
- Ownership or control over technical decisions

Public recognition is a thank-you for helping keep Udodi free and open source.

<script setup>

import { onMounted, onUnmounted, ref, computed, nextTick } from "vue";

const SPONSORS_URL = "https://cdn.udodi.dev/sponsors/sponsors.json";

const data = ref(null);
const error = ref(null);
const loading = ref(true);

function visible(list) {
  if (!Array.isArray(list)) return [];
  return list.filter((s) => s && s.public === true && s.logoApproved === true && s.logo);
}

const tiers = computed(() => {
  const d = data.value || {};

  return [
    { key: "platinum", label: "Platinum", className: "grid-platinum", items: visible(d.platinum) },
    { key: "gold", label: "Gold", className: "grid-gold", items: visible(d.gold) },
    { key: "silver", label: "Silver", className: "grid-silver", items: visible(d.silver) },
    { key: "bronze", label: "Bronze", className: "grid-bronze", items: visible(d.bronze) },
  ];
});

const hasAny = computed(() => tiers.value.some((t) => t.items.length > 0));

let tierScrollHandler = null;
let tierResizeHandler = null;

function initTierCarousel() {
  const grid = document.querySelector("[data-tier-grid]");
  const dots = Array.from(document.querySelectorAll(".tier-carousel-dots .tier-dot"));

  if (!grid || dots.length === 0) return;

  const cards = Array.from(grid.children);

  const pageSize = () => (window.innerWidth <= 640 ? 1 : 2);

  const pageCount = () => Math.ceil(cards.length / pageSize());

  const syncDots = () => {
    const size = pageSize();
    const pages = pageCount();

    dots.forEach((dot, index) => {
      const visible = index < pages;
      dot.hidden = !visible;

      if (visible) {
        const first = index * size;
        const last = Math.min(first + size, cards.length) - 1;

        dot.setAttribute(
          "aria-label",
          first === last
            ? `Show tier ${first + 1}`
            : `Show tiers ${first + 1} and ${last + 1}`
        );
      }
    });

    return pages;
  };

  const activePage = () => {
    if (!cards.length) return 0;

    const size = pageSize();
    const scrollLeft = grid.scrollLeft;
    let nearest = 0;
    let distance = Infinity;

    cards.forEach((card, index) => {
      const d = Math.abs(card.offsetLeft - scrollLeft);

      if (d < distance) {
        distance = d;
        nearest = index;
      }
    });

    return Math.min(Math.floor(nearest / size), pageCount() - 1);
  };

  const setActive = (index) => {
    const pages = syncDots();
    const safe = Math.min(Math.max(0, index), pages - 1);

    dots.forEach((dot, i) => {
      dot.classList.toggle("active", i === safe);
      dot.setAttribute("aria-selected", i === safe ? "true" : "false");
    });
  };

  const scrollForPage = (index) => {
    const size = pageSize();
    const cardIndex = Math.min(index * size, cards.length - 1);
    const card = cards[cardIndex];

    return card ? card.offsetLeft - grid.offsetLeft : 0;
  };

  dots.forEach((dot) => {
    dot.addEventListener("click", () => {
      const index = Number(dot.dataset.index);

      grid.scrollTo({
        left: scrollForPage(index),
        behavior: "smooth",
      });
    });
  });

  tierScrollHandler = () => {
    requestAnimationFrame(() => setActive(activePage()));
  };

  grid.addEventListener("scroll", tierScrollHandler, { passive: true });

  let resizeTimeout;

  tierResizeHandler = () => {
    clearTimeout(resizeTimeout);

    resizeTimeout = setTimeout(() => {
      syncDots();
      setActive(activePage());
    }, 80);
  };

  window.addEventListener("resize", tierResizeHandler);

  syncDots();
  setActive(activePage());
}

onMounted(async () => {
  await nextTick();
  initTierCarousel();

  try {
    const res = await fetch(SPONSORS_URL, { credentials: "omit" });

    if (!res.ok) throw new Error(`HTTP ${res.status}`);

    data.value = await res.json();

  } catch (e) {
    error.value = e?.message || "Failed to load sponsors";
  } finally {
    loading.value = false;
  }
});

onUnmounted(() => {
  const grid = document.querySelector("[data-tier-grid]");

  if (grid && tierScrollHandler) {
    grid.removeEventListener("scroll", tierScrollHandler);
  }

  if (tierResizeHandler) {
    window.removeEventListener("resize", tierResizeHandler);
  }
});

</script>
